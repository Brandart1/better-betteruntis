## New in this release

### Changed
- Android: in-app updates are now much faster and use the ota_update library instead of the app's own installer code. Only downloads with a matching checksum get installed. Android asks for "Install unknown apps" itself when needed.
- Messages are displayed with a well-tested HTML library instead of the app's own parser: headings, tables and nested lists look right now. Images in messages still aren't loaded (privacy); their description is shown instead.
- "What's new" and release notes use a standard Markdown library.
- Two-factor login codes come from a standard TOTP library (same codes as before).

### Known issues
- After Android's install screen the app can't tell whether the installation worked. If you cancel the installation, tap Close.
